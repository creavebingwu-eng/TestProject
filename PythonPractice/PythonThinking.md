# Python学习笔记

## 语法 - 数据的存储与运算

### 字面量：用于表示固定值的符号或表达式

### 变量：用于存储数据的容器

### 标识符：用于标识变量、函数、类等名称

### 数据类型：用于表示不同类型的数据

int：整数类型，用于表示整数
float：浮点数类型，用于表示带小数点的数值
str：字符串类型，用于表示文本数据
bool：布尔类型，用于表示真或假
list：列表类型，用于表示有序的可变数据集合
tuple：元组类型，用于表示有序的不可变数据集合
dict：字典类型，用于表示键值对的可变数据集合
set：集合类型，用于表示无序的唯一元素集合

### 字符串：用于表示文本数据，可以使用单引号、双引号或三引号来定义

### 运算符：用于执行各种操作的符号，如算术运算符、比较运算符、逻辑运算符等

### 输入输出：用于与用户进行交互，可以使用 input() 函数获取用户输入，使用 print() 函数输出结果

**注意事项**：在使用变量时，要确保变量已定义；在进行运算时，要注意数据类型的一致性

## 语法 - 流程控制语句

if 语句：用于根据条件执行不同的代码块
elif 语句：用于在 if 条件不满足时，提供额外的条件判断
else 语句：用于在所有条件不满足时，执行默认的代码块
match 语句：用于根据模式匹配执行不同的代码块
while 语句：用于在条件为真时重复执行代码块
for 语句：用于遍历序列（如列表、元组、字符串等）中的元素
break 语句：用于终止循环
continue 语句：用于跳过当前循环的剩余部分，继续下一次循环

## 语法 - 数据容器

列表：用于存储有序的可变数据集合，可以包含不同类型的元素
元组：用于存储有序的不可变数据集合，可以包含不同类型的元素
字典：用于存储键值对的可变数据集合，键必须是唯一的，值可以是任意类型
集合：用于存储无序的唯一元素集合，可以进行集合运算（如并集、交集、差集等）
列表和元组的区别：列表是可变的，可以修改元素；元组是不可变的，不能修改元素

**注意事项**：元组的不可变性使其在某些情况下更安全和高效，例如作为字典的键或存储不应被修改的数据。
